## Setup & Local Development

```bash
cd MAA-HEALTH-CARE-THERAPY
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm run preview
```

## Environment Variables

Copy `.env.example` to `.env` and optionally configure `VITE_FORMSPREE_ENDPOINT` for server-backed form submissions. When unset, the booking form routes enquiries directly via WhatsApp (`+91 95124 28000`).

## Deployment

The `dist/` output generated by `npm run build` is static and can be deployed directly to Vercel, Netlify, Cloudflare Pages, or GitHub Pages.
